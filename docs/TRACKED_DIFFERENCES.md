# Отслеживаемые различия между файлами

## Что проверяется

| Тип (`kind`)           | Название                  | Что именно сравнивается                                                                 |
|------------------------|---------------------------|-----------------------------------------------------------------------------------------|
| `sheet_order_or_names` | Листы книги               | Набор листов и их порядок в книге                                                       |
| `dimensions`           | Количество столбцов       | Общее число столбцов на листе (количество строк не проверяется)                         |
| `header_row_offset`    | Строка заголовков         | Заголовки обнаружены на другой строке (строка с наибольшим числом непустых ячеек)       |
| `header_leading_columns`| Пустые столбцы перед заголовками | Первый заголовок сдвинулся — добавился или убрался пустой столбец слева          |
| `header_count`         | Количество заголовков     | Число непустых ячеек в строке заголовков отличается                                     |
| `header_value`         | Значение заголовка        | Текст заголовка в конкретном столбце изменился или пропал                               |
| `formula`              | Формула                   | Наличие и содержание формул в ячейках; различаются три случая:                          |
|                        |                           | — формула удалена или заменена числом/строкой                                           |
|                        |                           | — в ячейке появилась формула, которой не было в образце                                 |
|                        |                           | — формула изменилась (например `=C2*D2` → `=C2+D2`)                                    |
| `number_format`        | Формат данных             | Числовой формат ячейки (например `#,##0.00`, `DD.MM.YYYY`, `0%`)                       |
| `merged_cells`         | Объединение ячеек         | Диапазоны объединённых ячеек на листе                                                   |

## Что НЕ проверяется (намеренно)

| Что                              | Причина                                                        |
|----------------------------------|----------------------------------------------------------------|
| Числовые значения в ячейках      | Данные меняются по содержанию, это норма                       |
| Текстовые значения в ячейках     | Данные меняются по содержанию, это норма                       |
| Шрифт, заливка, бордер           | Визуальное оформление, не влияет на работу скриптов            |
| Ширина столбцов                  | Визуальное оформление, не влияет на работу скриптов            |
| Высота строк                     | Визуальное оформление, не влияет на работу скриптов            |

## Как запустить

```bash
python -m excel_framework.validate_input <образец.xlsx> <входной_файл.xlsx>
```

Отчёты сохраняются в папку `reports/`:
- `input_vs_sample.html` — читаемый отчёт для человека
- `input_vs_sample.json` — машиночитаемый формат
