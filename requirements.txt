# NOTE: excel-framework-core declares requires-python >=3.10, but its code is
# 3.8-compatible (verified: full compile check + complete test suite on 3.8).

# The transitive pins below are required because --ignore-requires-python

# packaging / pluggy / typing-extensions releases that need Python 3.9+/3.10+
# and crash at import time on 3.8.
#
# The core package is installed editable from the sibling repository
# (../excel-framework-core, commit b1e71c2, ahead of tag v0.1.0), matching
# the project layout in AGENTS.md. If the sibling repo is not available,
# install from GitHub at the same commit instead:
#   pip install --ignore-requires-python \
#     "git+https://github.com/Sergey-Gromov/excel-framework-core.git@b1e71c292078d87d33aeb656012378a77e216e72"
